# TIGEPPS - Onboarding 2026.2

Aplicação web simples desenvolvida com React, TypeScript e Vite.

## Requisitos atendidos

- React + TypeScript + Vite
- Página responsiva
- Formulário com 4 campos
- Validação de campos obrigatórios
- Validação básica de e-mail
- Exibição dos dados preenchidos
- Persistência com localStorage
- Recuperação automática dos dados após atualizar a página

## Como executar

```bash
npm install
npm run dev
```

Depois, abra no navegador o endereço mostrado pelo Vite.

## Build

```bash
npm run build
```
